What's new

    First time only

    Chrome will ask you to pick your Creator Scout folder: the folder you chose with “Load unpacked”. Then allow Creator Scout to edit files in it.

    If Chrome offers Allow on every visit, choose it: later updates then install by themselves.

    Not sure which folder? Open chrome://extensions and look under Creator Scout: it says where it was loaded from.

      Or update by hand

      Download the zip, unzip it, copy everything inside over your Creator Scout folder (replace the files), then press Reload on Creator Scout in chrome://extensions.
